# layout 의 이해

## layout.tsx

- `_app.tsx 와 _document.tsx`의 역할을 함.
- 공통으로 적용할 내용을 작성하고, 공통으로 적용할 구조를 작성하는 곳
- `/src/app/layout.tsx`를 **글로벌 레이아웃**이라고 함.

```tsx
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import "./globals.css";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ko">
      <body
        className={`${geistSans.variable} ${geistMono.variable} antialiased`}
      >
        <div className="border-2 border-red-500">공통 레이아웃</div>
        {children}
      </body>
    </html>
  );
}
```

## /src/search/layout.tsx 생성

- 위의 경우는 글로벌 layout 이 적용되고 나서
- 해당 폴더의 layout이 같이 적용됨
- 특정한 경로의 별도 레이아웃을 만들고 싶으면 layout.tsx 파일을 생성하면 됨
- 이떄 children 은 별도로 작성해 줘야 함.

```tsx
import { ReactNode } from "react";

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <div className="border-2 border-green-500">
      검색 레이아웃
      <div>{children}</div>
    </div>
  );
}
```

## search 와 index 페이지에만 적용되는 레이아웃 만들기

- search 에는 `검색창 출력`

### **/src/app/(with-search) 폴더** 생성

- 검색창이 있는 layout
- () 폴더는 라우터 경로에 절대 영향을 미치지 않음.

  - http://localhost:3000/(with-search)는 적용되지 않음.
  - `라우터 경로에 영향을 미치지 않음.`
  - 오로지 레이아웃만 다르게 적용하는 용도

- /src/`app/(with-search)/layout.tsx` 생성

# React 19 - Server Component 의 이해

- React 18 버전에서 추가된 기능
  - 서버용 컴포넌트
  - 클라이언트용 컴포넌트와 구별하기 위해 사용
- 서버용 컴포넌트는 서버에서 딱 한번만 만든다.
- 또 인터렉션이 없는 컴포넌트다.

## 기준을 세워보자

- Next 에서는 무조건 서버 컴포넌트가 기본
- 만약, **use 훅**을 사용해야 한다면 별도로 `"use client"` 를 명시.
- 웹브라우저에서만 실행되는 라이브러리는 `"use Client"` 를 명시.

## 서버 컴포넌트 살펴보기

- `/src/app/(with-search)/page.tsx`
  - (with-search) 는 라우팅과 상관없음.

```tsx
// Next App router 에서는 서버 컴포넌트가 기본
export default function Home() {
  console.log("시작페이지");
  // 외부에 노출이 안됨
  // 그래도 .env 에 관리를 하도록 하자
  const supaKey = "123123";
  console.log(supaKey);
  return <div className="font-bold">Home!!</div>;
}
```

- 굳이 사용해야 한다면, 시나리오 index 보이는 곳에서 실행

```tsx
"use client";
import { useEffect } from "react";

// Next App router 에서는 서버 컴포넌트가 기본
export default function Home() {
  console.log("시작페이지");
  useEffect(() => {
    console.log("컴포넌트 웹브라우저에 보이면 실행"); // 마운트
  }, []);
  return <div className="font-bold">Home!!</div>;
}
```

## 클라이언트 컴포넌트로 만들려면

```tsx
"use client"; // 작성해줌.
```

## 검색창 컴포넌트 만들기

- 코딩 컨벤션(추천)

  - /src/app/components 폴더 생성 (비추천)

  - /src/components 폴더 생성 (추천)
    - `search-bar.tsx`
    - `searchbar.tsx`
    - `searchBar.tsx`
    - `SearchBar.tsx`

```tsx
"use client";
import React, { useState } from "react";

const SearchBar = () => {
  const [search, setSearch] = useState("");
  return (
    <div className="flex gap-2">
      <input
        type="text"
        value={search}
        onChange={(e) => setSearch(e.target.value)}
        className="border-2 border-gray-300 rounded-md p-1"
      />
      <button className="bg-blue-500 text-white px-3 py-1 rounded-md cursor-pointer">
        검색
      </button>
    </div>
  );
};

export default SearchBar;
```

- React Hook 을 쓸거면 "use client" 적용하도록 하자.
